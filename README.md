# ConversationApp

A real-time multilingual conversation assistant powered by Google Gemini.

- Backend setup and API documentation: [Backend/README.md](./Backend/README.md)
- Backend implementation: Express, TypeScript, Gemini Live speech-to-text, translation, three contextual replies, Gemini text-to-speech and PostgreSQL persistence.

See the backend README for environment configuration, database migrations, HTTP endpoints and the live WebSocket protocol.
